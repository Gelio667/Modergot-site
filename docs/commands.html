Команды

Доступность команд зависит от вашей роли и настроек доступа в чате.

Базовые

КомандаОписание
/helpСправка по командам
/meВаш ID, юзернейм и ссылка tg://user?id=...
/infoИнформация о пользователе (по ответу/упоминанию/ссылке)
/ranksСписок ролей и рангов

Верификация

КомандаОписание
/verify_onВключить верификацию
/verify_offВыключить верификацию

Сценарии

ГдеКомандаОписание
ЛС/importИмпорт JSON сценария (JSON удаляется после обработки)
Ограничение:
Импортировать JSON могут только модераторы, у которых есть права на все действия, описанные в сценарии.

Автомодерация

КомандаОписание
/automodЗапросить подключение автомодерации для этого чата
Важно:
Если вам нужна автомодерация, пожалуйста, свяжитесь с владельцем Boreal_builder через Modergot в личных сообщениях.
